Rules

No dark surfaces
Every background is white or a light grey. Dark type on light surface is correct — the restriction is about fills, not text.
Interactive is black
All buttons, links, tabs and controls use --action-default. There is no coloured brand button.
Red is LIVE only
--status-live never appears as decoration, hover, or emphasis. If it is red, a game is happening now.
Amber needs dark text
--status-shortlisted fails contrast as a text colour. Use it as a fill with --text-primary on top.

05

Corner cut

45° cut at top-left and bottom-right — the shape signature of the system

The signature shape of the system: a 45° cut on the top-left and bottom-right corner of every surface. All other corners stay square. Border radius is 0 everywhere except flags and status dots, which are full circles.

cut-s
8px · chips, badges, inputs, table cells
cut-m
12px · cards, buttons, list rows
cut-l
16px · modules, page-width surfaces

Anatomy — outlined variant

A CSS border is clipped away along the diagonal, so nothing is painted there and the cut disappears. Every outlined surface in this system is therefore built as two layers: the element itself is filled with the outline colour and clipped, and a single child inset by 1px carries the real surface colour. The 1px that shows around the edge — and along the diagonal — is the outline.

outline layer + fill layer
Element = outline colour, clipped. Child inset 1px = surface colour, clipped with the same corner size.
Filled — single layer
Filled surfaces need no second layer. Prefer this wherever an outline is not required.

Padding compensation

Content inset ≥ cut size at top-left
Correct — 16px padding against a 12px cut
Content clipped by the cut
Wrong — 4px padding, the corner eats the text
Figma build note — verified 11 Aug 2026
The fill layer is positioned absolutely rather than wrapping the content, so it costs no nesting level and maps 1:1 onto the Figma component. clip-path itself imports as a plain rectangle, so the cut is rebuilt once in Figma as el-00 CutSurface: a Boolean Subtract of one scaling rectangle minus two fixed-size corner triangles, each pinned by constraints (top-left triangle to Left+Top, bottom-right to Right+Bottom). Fixed corners are what keep the angle at exactly 45° when the surface is resized on one axis only — a single stretched vector path does not. Subtract rather than overlay, so the cut is transparent and works on any background, and so an outlined variant's stroke follows the diagonal.

Branded stroke

The four brand colours drawn as a single angular gradient around the edge of a surface. It is the one place all four appear at once, so it is reserved for a single hero container per page — the season status block on the landing page — and never used on a control or a row.

1px · cut-m
2px · cut-l

53%#0038FF
79%#FCA800
94%#ED0038
In Figma
Angular gradient, stroke position Inside, weight 1. Stops at 10 / 53 / 79 / 94 per cent. On an el-00 CutSurface instance this is a second stroke on the same vector, so the gradient follows the 45-degree corner without any extra layer. In HTML the surface carries the gradient as its background and a fill layer covers everything except the outline — which means the parent needs cut-out, a --n value, and a transparent border of the same width.

Elevation

Drawn with filter: drop-shadow, not box-shadow. A box shadow is painted outside the element and clip-path removes it entirely, so on any cut surface it is invisible. drop-shadow is applied after the clip and follows the 45° edge.

Naming
In Figma each flag becomes one component named el-flag / SRB, collected into a single component set with an ioc property, so a table row instance swaps flags through a dropdown rather than a layer replace. Because the source files are already named by IOC code, that set can be generated by importing the folder rather than renaming 230 layers by hand.
