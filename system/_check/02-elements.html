Note
Two properties do the work: content = code / name / both, and container = filled / plain. Filled is the standalone token; plain drops the fill so the tag can sit inside a table row without costing a nesting level. The flag carries no outline of its own. In filled the tag background already separates it. In plain the flag takes a 2px ring in that same background grey — it reads as the fill of the tag shrunk down to a halo, which is enough to keep white-heavy flags such as Japan, Poland and Finland off a white row without putting a hard line on the page.

el-26 Skeleton
The loading state. Every table, card rail and article on this site is populated from an API, and until now none of them had anything to show while that request is in flight.

Note
Skeletons mirror the real geometry — same row height, same column positions — so nothing shifts when the data lands. They are static shapes here; the shimmer is added in code and must be suppressed under reduced-motion.

el-29 AdSpace
A reserved advertising slot. It sits mid-page or above the footer, never in the header, and it is drawn as an explicit placeholder so a page never looks broken while a slot is unsold.
site · 1440 x 160 — full content width, house format
Advertising1440 x 160
billboard · 970 x 250
Advertising970 x 250
leaderboard · 728 x 90
Advertising728 x 90
half page · 300 x 600
Advertising300 x 600
MPU · 300 x 250
Advertising300 x 250
unsold — the slot collapses rather than showing an empty box
This slot is not sold
The page reflows and the slot takes no vertical space.
Note
The four sizes are the IAB standards a media pack is sold against — Billboard, Leaderboard, Half page and MPU — so a slot never has to be redrawn to fit a delivered creative. The 1440 site format is the exception: it is a house slot at full content width, sold and produced by the league rather than delivered by a network. Labelling is deliberate: the word Advertising stays visible above a live creative, which is both an editorial standard and a legal requirement in several markets. When a slot is unsold it collapses to nothing rather than leaving a grey rectangle on the page.
